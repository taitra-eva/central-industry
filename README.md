# 中部產業情報中心 / Central Taiwan Industry Intelligence

GitHub Pages website for public news indexing covering 機械、自行車、汽配、手工具.

## 第一版目前功能

- 16 組台灣／北美／歐洲／日本的 Google News RSS 搜尋，每日由 GitHub Actions 執行
- 保存文章標題、媒體、發布日期、原文網址及產業標籤，不擷取文章全文
- 首頁提供全文關鍵字、產業、地區與情報主題篩選
- 不使用付費 API，公開頁面請勿存入任何私人或內部業務資料

## 尚未完成

- 外文新聞自動翻譯與繁體中文摘要
- AI 每日因果分析
- 專業媒體直接 RSS/API 蒐集及驗證
- 官方統計數據自動連接

目前只是新聞索引第一版，不可將原文標題冒充已完成中文翻譯或 AI 分析。

## 網站發布

1. 進入 GitHub 儲存庫 Settings → Pages
2. Build and deployment 選擇 Deploy from a branch
3. Branch 選擇 main，資料夾選 /(root)，按 Save
4. 到 Actions → Daily industry news → Run workflow 手動進行首次資料更新
5. 在 Actions 頁面檢查執行結果與 data/news.json

每日排程時間為 UTC 00:23（台灣 08:23），GitHub 排程可能延遲或漏執行，應檢查執行狀態。新聞內容著作權屬原始發布者，資料以來源網站為準。

## 資料來源

- config/queries.json：各產業與地區新聞搜尋條件
- config/sources.json：候選專業媒體與官方來源（**尚未驗證直接可自動擷取**）
- scripts/collect.py：RSS 新聞索引蒐集程式

## 2026-11-19 最新採用規則（以程式實際狀態為準）
- 每次執行蒐集**原始發布日期在最近 14 天**的資訊；每天只有首次發現的文章會成為當日新收錄，重複文章不重寄。
- 網站**保留最近 30 天首次收錄**的所有新聞，產業頁不設 30 篇上限，按原文發布日期由新到舊。
- 為減少 Git 版本膨脹，不再每天提交重複的 archive 全量快照；主要歷史索引為 data/news.json。既有 snapshots 將於下次工作流程清除工作目錄，Git 歷史版本仍保留。
- 加入 ITIS 智網公開產業評析發現條件；ITIS 會員文章和付費年鑑不當成免登入全文來源。
- **全文繁體中文翻譯條件：** 必須已取得完整文章內容，而且持有必要的翻譯及站內刊載授權，才會出現在 article.html。其他第三方新聞僅顯示已翻譯標題、來源與跳轉原文，不擅自重製全文。現行免費 Google News RSS 一般只有標題與來源，故尚未實現每篇自動全文翻譯。
- 英／日文標題翻譯預先於更新流程執行，成功後寫入 news.json，使用者開網頁不需等待即時呼叫模型。Argos 離線模型仍需完成首次工作流程實測，無法保證每篇翻譯成功。
- 電子報程式的**未來版本**已取消「每類最多五則」與測試版「最多三則」，將列出當天新收錄全部新聞（跨產業重複去重）。使用者目前已貼入 Google Apps Script 的舊程式不會自動同步。依使用者指示先不進行電子報測試。

## 2026-11-19：原文閱讀必要步驟
- 在 GitHub Actions 的新聞蒐集後、翻譯前，已新增 `python scripts/read_articles.py`。
- 該步驟實際嘗試解析 Google News RSS 網址，連線至原始媒體網頁，透過 Trafilatura 抽取主文。
- 預設每輪最多嘗試 45 則，優先台灣文章；記錄 readable、blocked、unresolved、insufficient_text、read_failed 等狀態及檢查時間。無法取得全文不宣稱已閱讀。
- 可讀正文暫存於 Actions 工作目錄 `.article_texts.json`，不提交至公開 GitHub 資料檔；從已讀正文擇取段落、使用免費離線翻譯，呈現時標為「原文段落翻譯」，**尚非生成式 AI 詳細摘要**。
- 已將首頁摘要狀態與兩個連結壓在同一行；電子報仍不寄送。
- Google News URL 解析、媒體網站的反爬蟲限制及翻譯模型運作均需在下一次 Actions 執行時驗收。不同媒體可讀率可能不同。
